# 種牡馬データ調査のお願い（競馬ゲーム用）

ブラウザゲーム「競馬シミュレーター（趣味）」の種牡馬ロスターを増やすため、実在種牡馬のデータを調査して、データファイルを用意してください。受け取ったファイルは、こちらで原典照合のうえ、このリポジトリの `stallion-data/` フォルダに置いてゲームに組み込みます。

## 成果物

- 1バッチ＝10頭分を1ファイル（JSON 形式）にして、チャットでファイルとして渡してください。リポジトリへの配置はこちらで行います。
- ファイル名の例：`stallions_add_01.json`（バッチごとに連番）。
- 中身は下記スキーマの JSON 配列のみ（説明文はファイル外、チャット側で）。

## 対象

- 対象の種牡馬リストは、このフォルダ内の `TARGET_LIST.md` が正です。バッチ01から順に進めてください。
- 下記の「既存60頭」には入れないでください（重複禁止）。

## スキーマ（1頭分）

```json
{
  "name": "キタサンブラック",
  "sire": "ブラックタイド",
  "dam": "シュガーハート",
  "bms": "サクラバクシンオー",
  "grandam": "オトメゴコロ",
  "gbms": "ジャッジアンジェルーチ",
  "line": ["サンデーサイレンス", "ヘイロー", "ヘイルトゥリーズン"],
  "dist": [1800, 3000],
  "surface": "芝",
  "growth": "普通",
  "fee_tier": "S",
  "region": "domestic",
  "weight": 540,
  "source": "https://www.jbis.or.jp/horse/0001155349/"
}
```

### 各項目の決め方

- `name` / `sire` / `dam` / `bms`（母父）/ `grandam`（祖母）/ `gbms`（祖母父）：JBIS または netkeiba の表記どおり正確に。**母系（dam / grandam / gbms）まで全て必須**です。
- `line`：父系ラインを3階層（大系統→中系統→小系統）。例はサンデーサイレンス系の書き方です。
- `dist`：現役時代の実績から、その馬がトップレベルで走れた距離帯を [下限, 上限]（メートル、100m単位）。
- `surface`：主戦場が芝なら `"芝"`、ダートなら `"ダート"` のどちらか一方。
- `growth`：`"早熟"` / `"普通"` / `"晩成"` のいずれか。現役時代のピーク年齢で判断（2〜3歳ピーク＝早熟、4〜5歳＝普通、6歳以降＝晩成）。
- `fee_tier`：`"S"` / `"A"` / `"B"` / `"C"`。現実の種付け料と種牡馬としての格で判断し、既存の感覚に合わせてください（S＝キタサンブラック、エピファネイア級／A＝一流／B＝中堅／C＝カルストンライトオ、デュランダル級の安価な実力馬）。
- `region`：繋養地が日本なら `"domestic"`、海外なら `"overseas"`。
- `weight`：現役時代の代表的な馬体重（kg）。
- `source`：その馬の JBIS の馬ページ URL（照合に使うので必須）。

## 正確さのルール（最重要）

1. **推測で名前を埋めないでください。** 特に祖母・祖母父は捏造しやすい箇所です。原典で確認できない項目は `"不明"` と書き、チャット側でその旨を報告してください。
2. 全ての馬名は JBIS（https://www.jbis.or.jp）か netkeiba で実在と表記を確認してから書いてください。
3. 1頭ごとに `source` の URL を必ず付けてください。
4. 可能なら父系ラインごとにまとめてバッチを作ると、こちらも照合が速くなります。

## 進め方

- まず1バッチ（10頭）を作って URL を共有してください。こちらで照合し、問題なければ次のバッチに進みます。
- 形式や判断に迷う点があれば、勝手に決めず質問してください。
