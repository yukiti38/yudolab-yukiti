# 種牡馬 対象リスト（追加60頭・全6バッチ確定）

追加する種牡馬のリストです。全6バッチ×10頭＝追加60頭（既存60頭と合わせて120頭体制）。
バッチごとに10頭ずつ調査→照合→導入を進めます。

ルール：現役競走馬は対象外／死亡・用途変更済みの馬は対象外／ディープインパクト、キングカメハメハ等の「祖先枠」の馬は入れません（ゲーム内の血統表で祖先としてのみ登場するため）。
※印の馬は種牡馬入りの状況が要確認です。現役続行・死亡等が判明したら無理に入れず、予備リストから繰り上げます（その旨を報告してください）。
