# 種牡馬 対象リスト（追加80頭・全8バッチ確定）

追加する種牡馬のリストです。全8バッチ×10頭＝追加80頭（既存60頭と合わせて140頭体制）。
バッチごとに10頭ずつ調査→照合→導入を進めます。

ルール：現役競走馬は対象外／死亡・用途変更済みの馬は対象外／**種牡馬引退済みの馬も対象外**（2026-11-16 Terai決定。ラブリーデイ、ワールドエース、ディーマジェスティ、トランセンド、ウインブライト、ロジャーバローズ、ソーユーシンク、フェノーメノはこのルールと死亡・去勢により差し替え済み）／ディープインパクト、キングカメハメハ等の「祖先枠」の馬は入れません（ゲーム内の血統表で祖先としてのみ登場するため）。
※印の馬は種牡馬入りの状況が要確認です。現役続行・死亡等が判明したら無理に入れず、予備リストから繰り上げます（その旨を報告してください）。
