どんゆ、種牡馬データの調査の件、GitHub 連携ありがとう。受け渡しは直接 push 方式にします。

## 手順

1. リポジトリ https://github.com/yukiti38/yudolab-yukiti の `stallion-data/` フォルダにある `PROMPT.md` と `TARGET_LIST.md` を先に読んでください。データの形式・項目の決め方・正確さのルールは `PROMPT.md`、対象の種牡馬リストは `TARGET_LIST.md` が正です。
2. バッチ01の10頭から調査を始めてください。
3. 成果物は1バッチ10頭分の JSON ファイル（`stallions_add_01.json`、次は `stallions_add_02.json` …の連番）にして、**同じリポジトリの `stallion-data/` フォルダへ直接 push** してください。
4. push できたら、ファイルの URL を一言添えて知らせてください。こちら側の Muse（ゆきち）が JBIS などの原典と照合してゲームに組み込み、照合結果はフォルダ内の `notes_XX.md` に残します。

## push 権限について

- 書き込み権限がない場合は、push せずに **GitHub のユーザー名** を教えてください。Terai からコラボレーター招待を送ります。招待が届いたら承認して、改めて push してください。

## 注意

- 馬名、特に母系（母・祖母・祖母父）は推測で埋めないこと。確認できない項目は `"不明"` と書いて報告してください（詳しくは `PROMPT.md` の「正確さのルール」）。
- まずはバッチ01の1ファイルだけ作って push し、照合を通してから次に進んでください。
