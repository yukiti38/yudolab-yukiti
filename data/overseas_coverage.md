## レコード形式（overseas_races_2025.json）

各レコード12フィールド: `name`（日本語レース名、グレードページ表記）, `grade`（G1/G2/G3）, `country`（サイト表記）, `racecourse`（サイト表記）, `date_2025`（YYYY-MM-DD）, `month`, `week_of_month`, `surface`（芝/ダート/AW/null）, `conditions_raw`（altテキスト全文、またはG1詳細取得時はレースページ条件行）, `distance_raw`（条件行そのまま。ハロン表記は換算していない。無い場合はnull）, `race_page_url`（G1詳細取得時のみ）, `source_url`（抽出元のグレードページ）。

配列は date_2025 → country → grade → name 順にソート済み。パートファイルは `parts/` に国別で残してある（france_g1 / france_g23 / germany / italy / uk / ireland / usa / australia / newzealand / hongkong / uae / canada）。
